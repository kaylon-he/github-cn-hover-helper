# GitHub 中文悬浮助手

GitHub 中文悬浮助手是一个 Chrome/Edge 浏览器插件。安装后，在 GitHub 页面把鼠标放到按钮、菜单、导航或常见术语上，会看到对应的中文名称和功能说明。

它适合刚开始使用 GitHub，或者不熟悉 GitHub 英文界面的用户。

## 可以做什么

- 悬浮到 `Issues`、`Pull requests`、`Actions`、`Releases` 等入口时，显示中文解释。
- 悬浮到 `Star`、`Fork`、`Raw`、`Blame`、`Commits` 等按钮时，说明它们的用途。
- 不修改 GitHub 页面原文，只额外显示一个悬浮提示。
- 不调用 AI 或翻译接口，不上传页面内容。
- 仅在 `https://github.com/*` 页面生效。
- 支持 GitHub 浅色和深色模式。

## 安装

### 方式一：安装已打包版本

1. 找到插件压缩包：

```text
dist/github-cn-hover-helper-v0.1.0.zip
```

2. 解压这个 zip 文件。
3. 打开 Chrome 或 Edge。
4. 在地址栏输入：

```text
chrome://extensions/
```

5. 打开右上角「开发者模式」。
6. 点击「加载已解压的扩展程序」。
7. 选择刚才解压出来的文件夹。

### 方式二：直接加载源码目录

如果你拿到的是完整源码目录，也可以直接加载源码目录。

操作步骤同上，只是在「加载已解压的扩展程序」时选择包含 `manifest.json` 的那个文件夹。

## 使用方法

1. 打开任意 GitHub 页面，例如仓库首页、Issue 页面、Pull Request 页面或文件页面。
2. 把鼠标移动到你不理解的英文按钮或导航上。
3. 等待悬浮提示出现，查看中文名称和功能说明。

常见可提示的内容包括：

- `Issues`：议题区，用来管理问题、需求、Bug 和任务。
- `Pull requests`：合并请求区，用来提交和审查代码变更。
- `Actions`：自动化流程，用来查看构建、测试、发布和部署任务。
- `Raw`：原始内容，直接查看文件原始文本。
- `Blame`：逐行追溯，查看文件每一行是谁修改的。

## 看不到提示怎么办

可以按下面顺序检查：

1. 确认当前页面地址以 `https://github.com/` 开头。
2. 刷新 GitHub 页面后再试一次。
3. 进入 `chrome://extensions/`，确认「GitHub 中文悬浮助手」已启用。
4. 如果你修改过插件文件，点击插件卡片上的「重新加载」按钮。
5. 确认鼠标悬浮的是按钮、链接、菜单、导航等可交互元素。

## 隐私说明

这个插件只在本地浏览器中运行：

- 不需要登录。
- 不请求额外权限。
- 不发送网络请求。
- 不收集或上传 GitHub 页面内容。

## 扩充词典

如果你想增加更多 GitHub 术语说明，可以编辑：

```text
src/terms.js
```

格式：

```js
star: ["Star", "收藏仓库", "标记你感兴趣的仓库，方便以后找到，也表示认可。"]
```

如果要支持新的 GitHub 页面路径，也在 `src/terms.js` 里的 `pathRules` 增加规则。

修改后需要回到 `chrome://extensions/`，点击插件卡片上的「重新加载」，再刷新 GitHub 页面。
